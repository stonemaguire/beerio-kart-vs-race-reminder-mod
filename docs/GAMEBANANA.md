## Title

MK8DX Beerio Reminder

## Short description

Adds configurable Beerio reminder rounds to Mario Kart 8 Deluxe Local VS Race, with Frequency and Start settings plus a native Yes/No popup before scheduled races.

## Description

This mod adds two options to the Local VS Race settings menu:

- **Beerio Race Frequency** — how often a reminder round occurs.
- **Beerio Race Start** — which race starts the reminder sequence.

Both values automatically scale to the selected Race Count. For example, Frequency `4` and Start `3` prompts before races `3, 7, 11, ...`.

When a scheduled race is about to start, a native Yes/No popup appears. **No** returns to the pre-race screen and keeps the reminder due. **Yes** dismisses the popup and starts the race.

The included popup text can be changed for other house rules or non-alcoholic use. Source customization instructions are available in `docs/CUSTOMIZATION.md` on GitHub.

## Compatibility

- Mario Kart 8 Deluxe **4.0.0**
- Atmosphère
- Local VS Race
- Popup resource currently targets US English (`USen`)

Other game versions are not supported.

## Installation

Copy the included `atmosphere` folder to the root of the SD card and fully relaunch Mario Kart 8 Deluxe.

## Known issue

A yellow menu selection highlight can briefly flash in the lower-right area after choosing **Yes**. It is cosmetic and does not affect gameplay or reminder timing.

## Note

The reminder can be customized for any activity or non-alcoholic drink. If alcohol is involved, follow applicable laws and your own limits; never drink and drive.
